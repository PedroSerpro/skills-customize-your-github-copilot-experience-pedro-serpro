# 📘 Assignment: Mini To-Do App

## 🎯 Objective

Create a simple web application that lets users add, view, and complete tasks. Practice connecting Python logic to a basic web interface and handling form submissions.

## 📝 Tasks

### 🛠️ Build the Task List Page

#### Description
Create a page that displays a list of tasks and a form for adding new ones.

#### Requirements
Completed program should:

- Display a heading such as "My To-Do List".
- Show each task in a list with its current status.
- Include a form where the user can enter a new task title.
- Render the page using HTML templates or plain HTML responses.

### 🛠️ Handle Form Submission

#### Description
Process the form submission and add the new task to the app state.

#### Requirements
Completed program should:

- Accept input from a form submission.
- Add the new task to the list.
- Redirect or refresh the page so the new task appears.

### 🛠️ Mark Tasks as Complete

#### Description
Allow users to mark a task as completed.

#### Requirements
Completed program should:

- Provide a way to complete a task from the page.
- Update the task status from incomplete to complete.
- Display the completed task clearly.
