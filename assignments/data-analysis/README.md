# 📘 Assignment: Data Analysis

## 🎯 Objective

Learn core data analysis skills in Python by loading a dataset, exploring its structure, and visualizing key trends.

## 📝 Tasks

### 🛠️ Data Loading and Exploration

#### Description
Load the provided CSV dataset and perform basic exploration to understand its structure, variables, and summary statistics.

#### Requirements
Completed program should:

- Load a CSV file using Python (for example, with `pandas`)
- Display the first 5 rows of the dataset
- Show summary statistics for numeric columns, including mean and median

### 🛠️ Data Visualization and Insights

#### Description
Create visualizations that reveal patterns in the dataset and summarize the most important findings.

#### Requirements
Completed program should:

- Generate at least two different plot types (for example, a histogram and a scatter plot)
- Identify and describe at least two insights or trends from the data
- Save the plots as image files
